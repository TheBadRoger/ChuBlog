# 前端约定

首页只承担施工说明与导航，标题、进度文字、入口和页脚全部居中。大标题使用用户指定的“个人博客正在施工中”，只列真实已完成和仍未完成的功能。

颜色为白色 `#ffffff`、正文 `#202a2f`、次要文字 `#64727a`、分隔线 `#dce3e7`、浅底 `#f5f7f8` 和强调色 `#315e75`。使用系统中文无衬线字体，不从外部字体服务加载资源。标题靠字号和留白区分层次，不使用渐变、大幅插画或装饰标签。

阅读页和表单按阅读习惯左对齐。文章列表使用自然分行，标题及元信息比封面优先。桌面阅读宽度最多 720px，移动端至少保留 20px 边距。页面提供键盘焦点、显式标签、错误信息和真实空状态。

设计复核时移除了初始方案中的暖色纸张和陶土强调色，改用中性白底及克制的蓝灰，避免套用通用博客模板。唯一醒目的元素是施工页的大标题。
