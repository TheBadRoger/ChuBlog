# 开发进度

这篇文章记录博客的功能边界。它随首次安装发布到站长的个人仓库，后续由站长按实际进展更新。

## 已完成

- 导航首页、文章列表、搜索和标签筛选。
- Markdown 与纯文本阅读、多页链接和文章图片。
- 初始安装页面：填写网站名称、简介，使用服务器安装密钥创建唯一站长。
- ChuSQL 账户存储：用户 ID、唯一账号、加盐 Argon2id 密码哈希、创建时间、上次登录时间和权限。
- 自定义 ENUM 权限：BANNED、MEMBER、AUTHOR、MASTER。普通注册不获得发布权，站长可授权作者，不能创建第二个站长。
- 作者独立的 HTTPS Git 仓库，clone 和 push 均验证网站账号密码与发布权限。
- TOML 文章索引、多页入口、发布、更新和撤回，文章身份与系统时间由服务器记录。
- 文件白名单、容量限制、危险内容检查和错误索引暂存。索引错误时保留原版本。
- 站长首次建号后，自动将发文教程与开发进度写入其个人仓库，通过正常发布流程提供阅读。
- 独立 SQL 初始化文件，按字段使用整数、有限长字符串、时间戳和自定义枚举。
- 基础统计：公开文章数、标签数、正文大小与进程启动以来的文章请求数。
- Docker 一键构建部署、更新和卸载，可选数据库 CLI；域名与 HTTPS 由服务器反向代理管理。

## 待完成

- 内部文章：登录可读，并支持可选查阅口令。
- 评论系统：数据入库、内容长度限制和存储配额。
- 点赞与收藏：登录或匿名身份、去重、防刷和数据持久化。
- 每篇文章的浏览、点赞、收藏和评论统计，以及汇总排序。
- 热度算法、时间衰减和首页推荐。
- 精华文章、站长可见性管理、删除和内部文章设置。
- Git 发布后的站长审核机制，区分提交、待审核与正式发布。
- 在线文章管理和更完整的网站设置。
- HTML 富文本支持与对应的内容安全策略。

## 验证范围

本地执行源码检查、单元测试和不调用真实 Docker 的脚本测试。真实数据库、并发事务和部署联调应在指定环境手动验证，不能把编译成功等同于完整部署验收。
