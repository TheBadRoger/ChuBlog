# 安全限制

[返回项目首页](../README.md)

## 内容与容量

仓库白名单为根目录 `index.toml` 和仓库各相对目录下的小写扩展名 txt、md、markdown、png、jpg、jpeg、webp 普通文件。隐藏文件、证书、配置、脚本、链接、可执行位和子模块会使整次推送退回，文本也检查 PEM 标记。

| 范围 | 上限 |
| --- | --- |
| 索引 / 单个文本 | 64 KiB / 256 KiB |
| 单张图片 | 2 MiB、4096×4096 |
| 每个文章目录 | 12 张图片、总计 6 MiB |
| 每篇文章 | 64 个可达页面 |
| 每位作者 | 1000 个目录、14001 个文件、原始文件合计 64 MiB |
| 全站阅读快照 | 1000 篇文章、64 MiB |
| Git pack / HTTP 请求体 | 8 MiB / 9 MiB |
| 全部接收仓库 | 合计 256 MiB，达到后进入离线维护 |

正文和图片经过内容检查，危险 HTML、脚本和外链图片会被拦截。索引错误时保留上次生效版本，文件安全检查失败时拒绝整次推送。

## 身份与安装

密码使用 Argon2id 哈希保存。首次安装需要安装密钥，完成后安装入口关闭。普通注册不授予管理员或作者权限。

会话使用 HttpOnly Cookie，修改请求校验 Origin 和 CSRF。受保护接口和 Git 发布检查实时权限，数据库故障时认证失败。公共文章继续使用已导入快照。

## 协议与资源限制

| 范围 | 上限 |
| --- | --- |
| 普通 API 请求体 | 8 KiB |
| 安装、注册、登录 | 全局合计 10 次/分钟 |
| Git 密码失败 | 全局 20 次/分钟，仅失败验证计数 |
| 账户修改、文章管理及查阅口令验证 | 全局合计 60 次/分钟 |
| 密码哈希 / Git 执行 | 并发 2 / 1 |
| 前端 Git 接收 | 并发 2，请求体读取 15 秒 |
| fetch 协商 / CGI 响应 | 128 KiB / 64 MiB |
| Git 进程树 | 90 秒 |
| 用户 / 有效会话 | 各 1000 个，会话期限一小时 |

容器使用只读根文件系统和资源限额，数据库位于内部网络。公网入口应配置可信反向代理和 HTTPS，并定期更新依赖。

文章管理设置和访问授权应随持久卷备份。封禁或撤回不会清除 Git 历史和读者已获取的副本，备份要求见[运维文档](operations.md)。
