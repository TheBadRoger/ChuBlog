# 安全限制

[返回项目首页](../README.md)

## 内容与容量

仓库白名单为根目录 `index.toml` 和 `posts/目录/文件` 下的小写扩展名 txt、md、markdown、png、jpg、jpeg、webp 普通文件。隐藏文件、证书、配置、脚本、链接、可执行位和子模块会使整次推送退回，文本也检查 PEM 标记。

| 范围 | 上限 |
| --- | --- |
| 索引 / 单个文本 | 64 KiB / 256 KiB |
| 单张图片 | 2 MiB、4096×4096 |
| 每个文章目录 | 12 张图片、总计 6 MiB |
| 每篇文章 | 64 个可达页面 |
| 每位作者 | 1000 个目录、14001 个文件、原始文件合计 64 MiB |
| 全站阅读快照 | 1000 篇文章、64 MiB |
| Git pack / HTTP 请求体 | 8 MiB / 9 MiB |
| 全部接收仓库 | 合计 256 MiB，达到后进入离线维护 |

图片格式与内容经过解码验证。正文采用同目录页面链接，导入范围为入口可达页面、引用图片与封面。原始 HTML、危险协议、外链图片、控制符和双向隐藏字符会被拦截，代码块始终作为文本处理。前端对元数据和纯文本转义，Markdown 渲染结果经过清理。

索引语法或元信息错误时暂存提交，并保留上一生效版本。文件安全检查覆盖整份提交；有效索引中的入口缺失会撤回该篇文章。私有文章的正文、页面和资源在公共接口返回 404。

## 身份与安装

密码使用随机盐 Argon2id 慢哈希，账户、可重复昵称和 ENUM 权限保存在 ChuSQL。用户名为唯一小写字母账号，昵称始终按文本展示，登录和权限使用用户名及用户 ID。受保护接口、Git 请求及接收 Hook 查询实时权限，数据库故障时认证和接收进入失败状态。公共阅读继续使用已验证快照。

首次安装需要私有卷中的 256 位随机密钥并校验 Origin。站长与网站配置在同一事务提交，单例安装记录确保一次安装。成功后安装入口关闭，授权规则维持唯一站长。会话使用 HttpOnly、SameSite=Strict Cookie，HTTPS 场景附带 Secure；修改操作另行校验 CSRF。

## 协议与资源限制

| 范围 | 上限 |
| --- | --- |
| 普通 API 请求体 | 8 KiB |
| 安装、注册、登录 | 全局合计 10 次/分钟 |
| Git 密码失败 | 全局 20 次/分钟，仅失败验证计数 |
| 账户修改 | 全局 60 次/分钟 |
| 密码哈希 / Git 执行 | 并发 2 / 1 |
| 前端 Git 接收 | 并发 2，请求体读取 15 秒 |
| fetch 协商 / CGI 响应 | 128 KiB / 64 MiB |
| Git 进程树 | 90 秒 |
| 用户 / 有效会话 | 各 1000 个，会话期限一小时 |

Git gzip 同时校验压缩前后大小。每位作者使用独立仓库和锁，连接断开后任务继续持锁至 Git 结束。CGI 使用固定命令、白名单环境和参数，凭据传递范围为身份、哈希修订及 Hook 数据库连接配置；上传内容作为数据处理。固定 pre-receive Hook 在 Git quarantine 中验收提交。

Git 与 API 共享 UID 10001 和持久卷，容器采用只读根文件系统及资源限额。生产维护包含 Git 与解码库更新、可信代理入口、数据库内部网络和真实磁盘配额。接收仓库达到额度或历史超过 clone 响应限额时，由站长离线维护。

统计范围为文章数、标签数、正文大小与进程启动以来的文章请求数。请求计数随重启清零，访客识别与去重属于后续统计设计。

SQL 外部值统一经过 `Query.bind()` 编码，结构片段由程序提供。真实数据库测试覆盖引号、SQL 注入片段、重复昵称和特殊 UTF-8 字符；账户错误日志仅记录固定分类与操作阶段。
