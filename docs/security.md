# 内容限制与隔离边界

[返回项目首页](../README.md)

## 文件白名单

- 仅允许根目录 `index.toml`（唯一允许的 TOML 文件） 和 `posts/<目录>/<文件>` 内的 `.txt/.md/.markdown/.png/.jpg/.jpeg/.webp` 普通文件；扩展名使用小写。
- 拒绝证书扩展名、隐藏文件、`.gitignore`、脚本、配置、符号链接、可执行位、子模块和其他类型。
- 文本中的 PEM 证书/密钥标记也会拒绝。
- Git 接收层能直接拦截，因此非白名单内容使整次推送失败，不静默改变作者提交。

## 容量配额

- 根索引上限 64 KiB，每个文本文件上限 256 KiB；图片单张 2 MiB、每目录最多 12 张、尺寸 4096×4096；每个目录合计 6 MiB。
- 每位作者最多 1000 个目录、14001 个文件、原始文件合计 64 MiB；全站导入快照另限 64 MiB、1000 篇，超出时等待管理员处理。

## Git 接收限额

- Git 输入 pack 上限 8 MiB；全部作者接收仓库合计达到 256 MiB 后拒绝新 Git 请求，需要管理员离线维护。
- 此阈值是应用检查，生产还应为 Docker 数据盘配置真实文件系统配额。

## 正文解析

- 同一文章的相对链接仅可引用同目录已验证的文本或图片，禁止跨目录读取；只有从入口可达的最多 64 个页面、页面图片和封面可被导入。
- 使用成熟 Markdown 解析器，拒绝原始 HTML、危险链接协议、外链图片、控制符和双向隐藏字符；代码块是惰性文本，绝不执行 MDX、JS、仓库脚本、构建任务或上传内容。

## HTTPS Git 与进程边界

- Git 接收入口仅支持固定 `content.git` 的 Smart HTTP 服务。每次读取和写入都验证账号密码、账号状态和发布权；用户名映射独立物理仓库，不允许 URL 指定其他人的仓库。
- CGI 子进程使用清空后的环境、固定命令和受控参数，不传入 HTTP Authorization 或明文密码；不执行上传文件、仓库脚本或客户端提供的 Hook。固定 `pre-receive` Hook 在 Git quarantine 中检查候选提交。
- 危险文件会拒绝整次推送，不改写作者提交；未索引文件不导入线上内容。接收成功不等于已公开，TOML 错误仍沿用暂存机制。
- Git HTTP 请求体最多 9 MiB（含 8 MiB pack 与协议开销），fetch 协商最多 128 KiB；支持 Git 的 gzip 请求，同时限制压缩前和解压后的大小，避免解压炸弹。普通账户 API 仍为 8 KiB。前端接收请求体最多 15 秒，Git 进程树最多 90 秒，CGI 响应最多 64 MiB。
- API 同时最多一个 Git 执行任务，前端最多接收两个 Git 请求；并发或仓库锁冲突返回限流/冲突状态，由作者重试。客户端断开后执行任务仍持有锁至结束，避免接收并发破坏仓库。
- 全局 20 次/分钟 Git 密码失败限制，慢哈希并发最多 2；正常 Git 协商不计入失败额度。
- Git 与 API 使用 UID 10001，根文件系统只读，无宿主 Docker socket 或宿主 shell 权限。Git 解析器与 API 共享身份和持久卷，因此不是独立的进程安全沙箱，需要持续更新 Git 并依靠容器及服务器资源与磁盘配额限制。
- 接收内容再次验证后才导入按作者隔离的私有 Git 缓存与阅读快照。接收仓库达到容量上限时需要离线维护；较大历史可能超过 clone 响应限额，不能通过放开静态 Git 文件读取绕过。

## 账户存储

账户仅存 ChuSQL，权限列为自定义 `blog_permission` ENUM，注册默认 `MEMBER`；密码使用带独立随机盐的 Argon2id 慢哈希。没有 JSON 导入、文件回退或整数权限兼容。受保护接口和 Git Hook 查询数据库中的实时权限，数据库故障时拒绝认证或接收，不凭缓存放行。公共文章仍可从已验证快照读取。

## 首次安装边界

初始站长通过 `/setup` 创建，需要服务器私有卷中的 256 位随机安装密钥，并校验 Origin。安装请求与注册登录共用限流和密码哈希并发上限。网站元数据与站长在同一数据库事务写入，安装单例记录防止重复提交。完成后安装接口关闭；普通注册与授权不能创建第二个站长。安装状态读取失败时拒绝安装，不把数据库故障视为空站点。

## HTTP 与账户限额

- 普通 API 请求体 8 KiB；注册/登录合计全局 10 次/分钟，修改操作全局 60 次/分钟；密码哈希并发最多 2。
- 1000 用户、1000 个有效会话上限，一小时固定会话期限。
- 全局限制偏保守，后续可细化 IP/账户限制以改善公平性。

## 统计与隐私

- 统计不收集 IP/访客身份：公开文章数、标签数、Markdown 字节数、启动以来文章 API 请求数。
- 请求数不是独立访客数，重启后清零。

## 前端接入

- 文章 API 返回 JSON Markdown 与图片；Astro 前端将元数据作为文本输出，禁用原始 HTML、MDX 和危险链接，不能将接口字段直接作为 HTML 执行。
- 隔离不能替代 Git/解码库的持续安全更新。

## 索引暂存与生效版本

TOML 的语法或元信息错误只更新作者接收仓库中的暂存提交，不替换现有文章或时间记录。文件类型、模式、配额和正文安全检查仍会执行，不能通过破坏 TOML 绕过检查。有效索引中的入口不存在时，该文章不再生效。非公开文章的所有页面和资源均返回 404，防止绕过入口直读。
