# 前端

[返回项目首页](../README.md)

前端位于 `apps/web`，使用 Astro、TypeScript 和 Node 服务端渲染。网站名称和默认描述来自安装配置，页面正文使用统一阅读组件。

## 页面

| 地址 | 功能 |
| --- | --- |
| `/` | 安装前进入安装页，安装后提供全屏 Hero 和下滑导航 |
| `/setup` | 网站信息、管理员账号及昵称初始化，完成后进入登录页 |
| `/articles` | 文章列表、搜索、标签筛选和分页 |
| `/posts/用户名/文章ID` | 文章入口文档 |
| `/posts/用户名/文章ID?page=页面名` | 同文章的其他页面 |
| `/posts/管理员用户名/publishing`、`/posts/管理员用户名/development` | 两篇内置文章 |
| `/login`、`/login?mode=register` | 登录与注册（含昵称） |
| `/admin/users` | 管理员专属的用户状态与权限管理 |
| `/admin/articles` | 作者的个人文章管理；管理员额外可见用户文章审核与全部暂存索引 |
| `/account` | 昵称展示、密码管理和发布指引 |

## 本地开发

需要 Node.js 22.22 或更高版本，并启动后端 API：

```sh
cd apps/web
npm ci
cp .env.example .env
npm run dev
```

页面位于 `http://127.0.0.1:4321`。`API_BASE_URL` 默认指向 `http://127.0.0.1:3001`，Astro 同源转发 `/api/*` 和 `/git/*`。

```sh
npm run build
npm test
```

构建包含 Astro 和 TypeScript 检查。生产入口运行 `npm start`，Docker 端口见[部署文档](deployment.md)。

## 渲染与验证

浏览器使用 HttpOnly Cookie 和内存 CSRF。Markdown 输出经过清理，纯文本及元数据经过转义，页面设置 CSP。文章内链接按后端返回的页面与资源映射，服务故障显示重试提示。

真实浏览器联调在指定部署环境运行，命令见[开发文档](development.md#部署环境联调)。项目开发技能位于 `.agents/skills/`：[设计](../.agents/skills/frontend-design/SKILL.md)、[浏览器测试](../.agents/skills/webapp-testing/SKILL.md)、[界面检查](../.agents/skills/web-design-guidelines/SKILL.md)。

外观默认跟随系统，右下角使用单个按钮，按浅色、深色、跟随系统的顺序循环切换。图标展示当前模式，选择保存在本机。Hero 下方导航区域至少占满一屏，滚轮向下、手机上滑、键盘向下翻页或点击浏览提示，会平滑切换到导航起点，将 Hero 完整移出视口，随后继续普通页面滚动。Hero 标题有轻微入场效果，装饰线条缓慢移动。系统启用减少动态效果时，使用直接切换并关闭装饰动画。同源页面跳转通过浏览器原生 View Transition 做短暂交叉淡化，导航选中项的下划线在标签之间平滑移动，支持的浏览器自动启用，减少动态效果时保持直接切换。文章列表和正文的作者显示昵称，管理员作者旁展示“管理员”标记。账户页个人信息显示“昵称(用户名)”，用户名使用小字；账户管理使用同一行的“昵称（用户名）”。文章正文与账户发布指引共用正文排版及 Shiki 代码高亮，使用受限 CSS 类适配两种主题。

文章网址使用 `/posts/用户名/文章ID`，其他正文页使用 `?page=文件名`（省略扩展名），入口页使用文章主网址。`posts` 为固定网页路由前缀，文章 ID 取自 `index.toml` 的 id；folder 指定仓库内的相对目录，支持至少一层文件夹及多层目录，与网址独立。内部 API 和索引继续使用 `用户名~文章ID` 区分同名文章。


账户信息在服务端按当前 Cookie 验证，并在单次页面请求内复用结果，导航直接显示对应状态。页面返回浏览器后复用该结果，历史页面恢复时重新验证会话。读取失败展示重试提示，401 表示需要登录，403 表示账户或权限受限。用户信息和 CSRF 随当前页面提供，页面保持 `no-store`。

异步读取和保存使用带文字的加载指示，页面跳转和搜索使用顶部进度条。发布授权列表和同步状态并行读取，用户列表先返回即可先显示；列表用文档片段一次插入，各区域提供独立加载与错误状态。所有动画遵循减少动态效果设置。

管理员在“文章管理”中提供精华标记、四档可见性、可选查阅口令、封禁/解封和绝密文章授权；隐藏等级由作者设置。作者在“文章管理”的个人文章管理区设置自己文章的可见性、半/全隐藏、口令和绝密授权，并查看自己的暂存索引；管理员在“文章管理”的用户文章管理区审核 Open/Blocked。账户页只保留身份与发布指引。受限正文页由 SSR 解析锁定 JSON，渲染高斯模糊背景与固定前景：登录、口令或“无权访问”，半隐藏才显示文章元信息。SSR 读取列表、正文与子页面时转发当前请求的 Cookie，图片请求经过同源 API 执行相同权限检查。

文章隐藏等级按作者身份开放设置；管理员编辑自己创作的文章时同样可调整，编辑他人文章时禁用。机密文章固定使用全隐藏。
