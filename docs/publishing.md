# 文章发布

[返回项目首页](../README.md)

完整操作教程保存在[内置发文文章](../apps/api/starter/posts/publishing/main.md)。首次安装后，它以管理员名义发布，首页提供阅读入口。本页汇总作者仓库与索引规则。

## 账户与仓库

管理员在账户页授予 AUTHOR 权限，作者使用网站账号密码克隆账户页给出的 HTTPS 地址。所有作者共享 `/git/content.git` 入口，服务端按账号分配独立仓库；克隆和推送均校验身份与发布权。

安全凭据管理器可以保存密码。保持 HTTPS 证书验证开启，账号密码保存在系统凭据管理器中；Git 的 `credential.helper store` 使用明文存储。

## TOML 索引

根目录 `index.toml` 为 UTF-8，每篇文章对应一个 `[[articles]]`：

```toml
[[articles]]
id = "first"
folder = "posts/first"
title = "第一篇文章"
description = "文章简介"
tags = ["随笔"]
public = true
# cover = "cover.png"
# entry = "main.md"
```

| 字段        | 规则                                                                                 |
| ----------- | ------------------------------------------------------------------------------------ |
| id          | 作者内唯一，1–40 位小写字母、数字和中间短横线                                        |
| folder      | 仓库内的相对目录，支持中文、空格及嵌套；至少一层文件夹，最多 91 个 UTF-8 字节、16 层 |
| title       | 必填，最多 240 字节                                                                  |
| description | 默认空，最多 1000 字节                                                               |
| tags        | 默认空，最多 12 项，每项最多 80 字节                                                 |
| cover       | 可选，同目录图片文件名                                                               |
| public      | 默认 false（草稿）；true 表示作者发布，最终可见性仍受管理员设置约束                  |
| entry       | 默认 main.md，支持 md、markdown、txt                                                 |

同一目录只登记一次，文件名建议使用英文字母、数字、短横线和下划线。作者和时间由服务器记录。

文章地址为 `/posts/用户名/文章ID`。入口页可以通过同目录相对链接连接其他页面，示例见 [index.toml](../content/index.toml) 和[多页正文](../content/posts/welcome/main.md)。

## 提交与撤回

每次推送包含一个直接接续远端 main 的提交，空仓库首次推送为根提交。协议范围为 main 的线性历史；多次本地提交整理为一个提交后推送。

| 内容                         | 处理结果                         |
| ---------------------------- | -------------------------------- |
| 有效索引与入口               | 发布或更新文章，保留首次公开时间 |
| 有效索引移除条目，或入口缺失 | 撤回该文章及页面资源             |
| `articles = []`              | 撤回全部文章                     |
| 索引缺失、语法或元信息错误   | 暂存提交，沿用上次生效版本       |
| 文件、内容或容量违规         | 整次推送退回，保留远端分支       |

索引错误时保留上次发布内容，文件或容量违规时整次推送失败。具体限制见[安全文档](security.md)。

## 管理员设置

管理员在 `/admin/articles` 设置精华、可见性、口令和封禁。作者可以设置自己文章的可见性、隐藏等级和授权用户。机密文章固定全隐藏，查阅口令至少 6 个字符。

秘密文章需要登录，机密文章需要口令，绝密文章需要指定授权。半隐藏显示摘要，全隐藏不显示文章条目。

封禁文章对外显示已删除。作者修改正文并推送后可自动解除封禁，重推相同内容不会恢复。撤回和封禁都不会清除 Git 历史或已克隆副本。
