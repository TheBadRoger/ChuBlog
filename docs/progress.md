## 已实现

| 范围 | 完成内容 |
| --- | --- |
| 安装与账户 | 安装密钥验证、网站名称与简介、唯一管理员建号；ChuSQL 持久保存账户、昵称、Argon2id 密码哈希及安装记录；注册、登录、退出和改密 |
| 权限 | BANNED、MEMBER、AUTHOR、MASTER 四级数据库权限；管理员授权作者及封禁账户；服务端检查会话与实时权限，修改请求校验 Origin 和 CSRF |
| Git 发布 | 作者独立 HTTPS 仓库，网站账号密码及发布权验证；单次一个线性提交、仅 main；文件、路径、图片、容量和内容安全校验 |
| 文章同步 | TOML 索引、Markdown 与纯文本、多页和图片；系统记录作者及时间；错误索引暂存并保留生效版本，入口或条目移除后撤回；数据库文章索引可重建 |
| 文章管理 | 管理员设置精华、默认/秘密/机密/绝密可见性、查阅口令和开放/封禁审核；封禁时记录正文哈希，作者修改推送后自动开放；设置保存在私有 collection.json，后续作者推送不覆盖 |
| 受限阅读 | 秘密需登录、机密需口令、绝密需指定用户；半/全隐藏控制列表元信息与锁定页；正文、子页面和图片统一校验权限；口令解锁和指定授权持久写入 blog_article_access，改口令撤销旧 PASSWORD 授权 |
| 阅读前端 | Astro SSR 导航首页、文章列表、搜索、标签、分页、精华入口与筛选、作者昵称及管理员标记；暗色模式、代码高亮、多页导航和加载提示 |
| 部署与维护 | Docker 内构建 Rust、ChuSQL 和前端；部署、更新、卸载脚本；独立持久卷、资源限制、反向代理接入及可选数据库 CLI |

访问顺序为先审核、再可见性、最后隐藏等级。封禁文章对外统一返回“文章不存在”，作者和管理员仍可读取；作者修改正文并推送后，哈希变化会自动解除封禁。机密文章必须全隐藏，半隐藏文章可在列表显示摘要，正文页渲染固定前景锁定层；全隐藏不显示条目或元信息，仅能通过链接进入。

设置保存在私有 `collection.json`，策略投影到 `blog_article_policy`，持久授权保存在 `blog_article_access`。封禁不删除 Git 历史、已克隆副本或私有缓存；备份必须同时包含 `collection.json` 和数据库授权表。

新增回归覆盖游客读取正文、子页面和图片的权限边界，空 Cookie 与过期会话，未登录调用管理及解锁接口，公开导出排除受限内容和口令哈希，以及作者重新推送后保留管理员设置。

完整管理员登录、CSRF、普通读者口令验证、口令轮换、封禁哈希、策略投影和持久授权流程已在隔离数据库中验证。新增回归覆盖管理员编辑自己文章的隐藏等级、绝密授权与策略修改串行执行、指定授权跨会话保留及撤销，以及策略投影失败后独立重试。临时移除授权锁时并发回归失败，恢复锁后通过。

授权表改用组合字符串主键，避免当前 ChuSQL 不支持的表级联合 UNIQUE 语法。共享身份目录会被部署初始化用例修改，完整数据库测试按单线程执行，避免并行用例使其他数据库会话失效。浏览器回归已补充管理员自己文章的隐藏等级保存流程，尚未执行；实际容器与 HTTPS 验收仍见[部署环境联调](development.md#部署环境联调)。
